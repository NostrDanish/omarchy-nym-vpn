# Security Audit — omarchy-nym-vpn — 2026-10-20

## Summary
QML panel + Python helper (`status.py`, 43 KB — read in full) driving the Nym VPN daemon (`nym-vpnc`). Overall **well-engineered defensively**: all subprocess calls use argv lists (no `shell=True`), country codes are regex-validated (`^[A-Z]{2}$`), DNS server input is charset-validated, PIDs digit-checked, location caches chmod 0600, the account mnemonic comes from env (`NYM_MNEMONIC`) only, is quote-stripped, and is redacted from error output. No command-injection path via shell was found. Findings: 0C / 0H / 2M / 1L.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| M1 | MEDIUM | status.py `socks5()` | `addr` is validated only for containing `:` before being interpolated into a session-script line fed to `nym-vpnc start-session` stdin. A value containing a newline would inject additional daemon session commands (e.g. `exit`/`dns set`). Local-attacker/self-XSS surface via the panel only, but trivially fixed. | Reject `\\n`/`\\r` and validate `addr` against a strict host:port regex before building the session line. Same defense for any future free-text session fields. |
| M2 | MEDIUM | bin/nym-vpnc | A 6.7 MB prebuilt `nym-vpnc` binary is vendored in-repo. Provenance/integrity cannot be verified from the repo (no checksum, no build attestation); anyone cloning runs it against their VPN account daemon. | Ship a SHA-256 manifest + source link, or fetch from signed upstream releases at install time. |
| L1 | LOW | status.py `AUTH_FIX` | The suggested polkit rule auto-allows `com.nymvpn.vpnd.unix-access` for active sessions — weakens daemon auth by design (documented, user-opt-in). | Keep as-is; ensure docs frame it as a convenience/security trade-off. |

## Secrets Check
status.py, manifest.json paths, and bin/ listing reviewed; org-wide searches for `nsec1`, `sk-`, `xai-`, `api_key`, `nostr+walletconnect://`, `PRIVATE KEY` — **no secrets found**. Mnemonic handling is env-only with error redaction (good).

## Dependency Notes
Vendored nym-vpnc binary (see M2); Python stdlib only otherwise. QML panel targets omarchy-shell.
