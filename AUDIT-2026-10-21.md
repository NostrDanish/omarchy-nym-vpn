## Findings
| ID | Severity | File/Area | Issue | Fix |
|----|----------|-----------|-------|-----|
| M-1 | MEDIUM | status.py `socks5()` | Listen address validated only for containing `":"`, then interpolated into a newline-joined session script (`socks5 enable --socks5-address {addr}`). An address containing `\n` injects an arbitrary extra nym-vpnc command into the session. Panel-supplied input today, but the helper is a CLI surface. | Reject whitespace/control chars: `re.fullmatch(r"[0-9A-Za-z.:\[\]-]+", addr)` and validate host/port. |
| M-2 | MEDIUM | bin/nym-vpnc | Vendored 6.7 MB prebuilt binary (6,718,728 bytes) committed with no checksum/signature/provenance note. Supply-chain risk if repo is cloned as an install source. | Fetch from upstream Nym releases at install time with pinned SHA256, or document provenance + hash. |
